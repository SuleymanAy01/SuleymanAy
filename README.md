# Süleyman Ay — Siyah & Altın Manga Tema

GitHub Pages için statik web sitesi. `index.html`, `privacy.html`, `style.css`, `script.js` ve `assets/` klasörünü deponun **kök dizinine** yükleyin. ZIP dosyasını doğrudan yüklemeyin.

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

Özel alan adı için Pages ayarlarında `suleymanay.com` yazın ve Squarespace DNS kayıtlarını GitHub Pages yönergelerine göre yapılandırın. DNS kayıtlarını doğrulamadan değiştirmeyin.

Gizlilik metnini yayınlamadan önce gerçek veri işleme ve barındırma ayarlarına göre gözden geçirin.
